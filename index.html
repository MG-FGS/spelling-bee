How to manage this week's words
  1. Add: Type one spelling word on each line, or paste a list. To include an example sentence, type a vertical bar (|) after the word, then the sentence. Example: garden | The garden has flowers.
  2. Edit: Tap inside the box and change the word or its sentence on that line.
  3. Remove: Delete the entire line containing the word you want to remove.
  4. Name your list: Change the list name to something like Week of October 26.
  5. Save: Tap Save this week's words and confirm. This replaces the current list and resets scores and missed words.

Tip: Export a backup first if you want to keep the previous week's list and results. Changes are saved only on this device/browser.
